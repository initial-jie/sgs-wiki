### 分发血量牌和弹夹牌（Rusty gunshots）

每个角色获得对应血量上限的血量牌；游戏过程中将血量牌置于角色牌下方，露出当前的血量值。扣减血量时，将武将牌右移挡住被扣减的血量。当血量值减至 0 及以下时，该角色进入濒死状态：所有角色可以对其使用【补丁】直到其血量回复至 0 以上。若未能回复到 0 以上，则该角色死亡。

弹夹牌则竖置放入角色牌下方，消耗或补充子弹时，移动弹夹牌至对应数量的子弹。每回合开始时，将子弹数调整至子弹上限。分发完成，游戏开始。

（右侧配图：角色牌「徐庶」叠在血量牌与弹夹牌上的摆放示意，图注：**牌的摆放**）

## 进行游戏（-RUSTY GUNSHOTS-）

进行游戏时，由至高之脑开始，按逆时针方向以回合的方式进行。

即每名玩家有一个自己的回合，一名玩家的回合结束后，右边玩家的回合开始，依次轮流进行。

每个玩家的回合共分为三个阶段：摸牌阶段→出牌阶段→弃牌阶段。

- **摸牌阶段** 你从牌堆顶摸等于角色补给数张牌；将子弹调整至子弹上限。
- **出牌阶段** 你可以使用任意张牌，但必须遵守以下规则：1. 任何一名角色面前不能放有两张同名的延时牌（详细见下文）。

## rule2/p2.jpg —— 射击相关介绍 / 命中判定（说明书第 11 页）

**拍照者注释**（橙色大字叠加在页面中部）：「射击说明」

- **射击相关介绍：** 发射 1 枚子弹的行为称为进行一次射击，因此当玩家使用【扫射】发射多枚子弹时则会进行多次射击；上文中提到了一个重要的概念：**命中判定和命中点数**
- **命中点数（②）：** 位于牌的左上角；当角色对目标射击（即发射 1 枚子弹时）时，需要翻出牌堆顶的牌进行判定，如果命中点数大于 0，则代表命中；这个判定被称为**命中判定**，一般情况下，所有牌点数都大于 0，但是战场瞬息万变，存在很多情况会减少命中点数，最常见的情况是，如果一个角色和你不相邻，那么他离你越远，越难命中，计算方式是，你们之间每隔着一个角色（取最短路线），命中点数便会减 1；所以如果隔着两个角色，命中点数则会 -2，依此类推；如果减至 0 及以下，变成未命中的状态。还有一些游戏牌的效果可以短暂增减命中点数，灵活运用这些牌，助你夺得游戏胜利！

**此外卡牌上有两种特殊的命中判定**

- **爆头（靶心图标）：** 如果判定出爆头，无视点数的增减，直接命中，且此射击伤害 +1。
- **哑火（图标）：** 如果判定出哑火，无视点数的增减，无法命中；

在某些技能中，需要检定卡牌的点数，爆头视为 5 点、哑火视为 0 点；但是需要注意，爆头和哑火的点数无法增减；其他点数也无法通过增减变成爆头或哑火。

- **牌堆中的命中点数构成**

| 点数 | 张数 |
|---|---|
| 1 点 | 40 张 |
| 2 点 | 30 张 |
| 3 点 | 20 张 |
| 4 点 | 10 张 |
| 爆头 | 4 张 |
| 哑火 | 4 张 |

- **射击的具体流程如下：**

流程图：
1. 选择一名角色作为目标射击
2. → 目标选择是否使用【翻滚】抵消这张射击牌
3. → 如果玩家选择抵消则结算结束,未能射击成功;如果玩家选择不使用,则进行命中判定
4. → 命中判定成功则对目标造成 1 点伤害(注意目标不能在此时使用翻滚去抵消射击了;此时后悔,为时已晚!)　／　如果命中判定失败则结算结束,未能射击成功。

## rule2/p4.jpg —— 翻滚注意 / 战术牌 / 装备牌（说明书第 12 页）

**拍照者注释**（绿色大字叠加在页面中下部）：「战术牌和装备牌」

需要注意：使用【翻滚】仅能抵消一发子弹，即一次射击，如果玩家使用了【扫射】朝目标发射了 3 枚子弹，会对目标连续进行三次射击！也就是说目标要使用三张【翻滚】去依次抵消每发子弹，当然目标也可以选择使用一到两张【翻滚】去抵消等量的子弹，承受未被抵消的其余子弹。

### 战术牌

分为普通**战术牌**和**延时战术牌**（简称延时牌）

战术牌一般伴随各种各样的效果，正常的战术牌使用后立即生效并执行牌面效果；但是有一种特殊的战术牌需要注意，即延时（战术）牌。

延时牌在卡面上表现为横版的牌，当玩家使用延时牌时，须将此牌横着放到指定的玩家面前，在该玩家回合开始时，此牌才能生效（引爆）。
（右侧配图：横版黄色牌「微型黑洞」，点数 1，图注 **延时牌**）

在这张延时牌没生效前，其他玩家可以对其进行干涉，以令它无效或提前生效分为三种方法

1. 玩家在出牌阶段对其他玩家面前的延时牌进行射击（注意会占用射击次数），对延时牌射击会进行命中判定，延时牌的位置视为与拥有者的位置相同，但拥有者不可翻滚来抵消。当射击命中后，射击者选择令这张延时牌在此时立刻生效（提前引爆），或者无效，然后放到弃牌堆。但是玩家无法射击自己面前的延时牌。
2. 玩家使用【剥离】可以选择延时牌为目标。
3. 此牌在目标回合开始时，所有玩家可以用【无懈可击】抵消。

### 装备牌

玩家使用装备牌时，将装备牌放到自己面前，装备牌持续生效；但需要注意，每名玩家面前的装备牌数和不可超过 3，如果超过 3，需要弃置其中一张牌。面前的装备牌允许有同名的牌。
（左下配图：黑绿色牌「彩虹弹匣」，点数 1，卡面小字"你的子弹上限 +1。"，图注 **装备牌**）

## rule2/p5.jpg —— 角色死亡 / 游戏结束（说明书约第 13 页）

## 角色死亡（-RUSTY GUNSHOTS-）

当一名角色的血量降到 0 时，即进入濒死状态，除非自己或他人在此时用【补丁】来挽救该角色，否则该角色死亡。死亡的角色亮出身份牌，弃置该角色所属区域的所有牌，然后执行奖惩。

任何角色杀死一名病毒，立即摸三张牌。若至高之脑杀死了免疫官，至高之脑需要弃置所有牌。

## 游戏结束（-RUSTY GUNSHOTS-）

当以下任意一种情况发生时，游戏立即结束：

**至高之脑死亡**：此时若异变是唯一存活的角色，则异变获胜。除此之外的情况为病毒获胜；

**所有的病毒和异变都死亡**：至高之脑和免疫官都获胜。

⚠ **需要注意：** 当脑和异变以外的角色死亡，双方进入单挑环节时，异变抢夺（接下页）

## FAQ（-RUSTY GUNSHOTS-）

### 游戏牌相关（Rusty gunshots）

**Q：** 我对拥有【无声的伪装】的角色使用【扫射】，进行了三次射击，如果都没命中，目标摸几张牌？
**A：** 三张。

**Q：** 一名角色的回合内，如果此时有【致命闪光】被引爆，命中判定出爆头可以命中吗？
**A：** 可以命中，爆头无视点数的增减。

**Q：** 我使用【夺取】，如果自己没有子弹，目标可以不给牌吗？
**A：** 可以，此时将无事发生。

**Q：** 我使用【翻滚】增加命中判定后，下一张使用的【扫射】进行多次射击是每次射击都增加命中还是只有首次射击增加？
**A：** 此次【扫射】中，每次射击都增加命中。

**Q：** 玩家使用【扫射】发射多枚子弹，使用翻滚抵消的流程是一次次来还是单次使用多张翻滚？
**A：** 每次射击单独结算，结算完一次后再执行下次射击的结算。

**Q：** 如果我的子弹数已达到子弹上限，那我可以使用【化血为剑】吗？
**A：** 可以使用，仍可以获得子弹，但超过上限的部分会在下个摸牌阶段调整到子弹上限，不会累积。

**Q：** 我使用【彩虹弹匣】，令子弹上限 +1，会立刻获得 1 枚子弹吗？
**A：** 不会，子弹将在下个摸牌阶段补至上限。

**Q：** 【无懈可击】可以仅抵消【EMP 清道夫】或【微型黑洞】仅对一名角色的效果吗？
**A：** 不可以，【无懈可击】将抵消一整张牌对所有角色的效果。

**Q：** 【轮盘赌】没有翻出射击牌怎么办？
**A：** 无事发生，双方都不会受到伤害。

**Q：** 我使用【翻滚】可以抵消非射击牌向我发射的子弹吗？
**A：** 可以的，包含因技能发射的子弹也可以。

### 武将相关（Rusty gunshots）

**Q：** 小乔的"子弹诡计"如何判断子弹方向？
**A：** 从小乔到目标之间，相隔最少角色的路径即是这个子弹射击的方向，如果两边的角色数一致，方向由小乔自行决定。

**Q：** 孙鲁班的命中判定反转，如果判定出爆头和哑火怎么办？
**A：** 爆头会反转成哑火，哑火会反转成爆头。

**Q：** 大乔在"安全协议"解除后，可以将非最后一张手牌的射击牌当【扫射】使用吗？
**A：** 不可以，仍旧需要是最后一张手牌才能当做【扫射】。

## rule2/p8.jpg —— 1V1 模式正文 / 开发人员名单（说明书末页）

游戏开始时，在玩家两侧各放置一张 npc 机器人，每名玩家发放五张角色牌，然后从中选择两张角色牌，均选择完成后明置所有所选角色牌并选择其中一张出战。

两名玩家依次进行回合，先手玩家首个摸牌阶段少摸一张牌；玩家拥有当前出战的武将牌上的技能、补给数、子弹上限等。

每当自己的回合开始时，可以将出战角色切换为另外一名，**两名角色的体力值单独计算。**

当一名出战角色死亡后，须弃置所有手牌，重新摸四张牌，保留装备区内的牌，将出战角色切换至另一名，**安全协议解除。**

当一名玩家的两张角色牌全部阵亡时游戏结束，另一方玩家获得胜利。
