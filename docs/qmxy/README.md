## 2. 规则骨架(对照三国杀)

### 2.1 身份
| 枪鸣锈语 | 对应三国杀 | 备注 |
|---|---|---|
| 至高之脑 | 主公 | 开局亮;多 2 张候选角色先选;持【超意识】(病毒数 > 脑+免疫官数 时 血量/补给/子弹上限各 +1);**没有主公技** |
| 免疫官 | 忠臣 | 脑杀免疫官 → 脑弃全部牌 |
| 病毒 | 反贼 | 任何人杀病毒摸 3 |
| 异变 | 内奸 | 单挑时**夺走脑的超意识**(脑失效、异变获得) |

配置表(说明书):3 人 1/0/2/0 + 3 NPC 隔座;5 人 1/1/2/1;6 人 1/1/3/1;7 人 1/2/3/1;8 人 1/2/4/1。4 人表没拍到(百度知道答案说 2~10 人)。
终局:脑死 → 异变是唯一存活则异变胜,否则病毒胜;病毒+异变全死 → 脑+免疫官胜。

### 2.2 角色属性(三个数字,不止体力)
- **血量上限**(勾玉,3~5)—— 同时是手牌上限。
- **补给**(卡牌图标,0~4)—— 每回合摸牌数。
- **子弹上限**(尖括号图标,0~6)—— 每回合开始补满;射击与部分战术牌消耗子弹。
- 装备最多 3 件(可同名);彩虹弹匣 +1 子弹、手臂拓展 +1 补给、自我遥控器 互换补给/子弹。

### 2.3 回合
摸牌(补给数 + 子弹补满)→ 出牌 → 弃牌(手牌上限 = 血量上限)。脑先手,**逆时针**。起手 4 张。

### 2.4 射击与命中判定(核心差异)
- **没有距离/攻击范围**。任何目标都能打,远近只影响命中率。
- 每发子弹一次判定:翻牌堆顶,看左上角**命中点数**(每张游戏牌都带,分布 1 点×40 / 2 点×30 / 3 点×20 / 4 点×10 / 爆头×4 / 哑火×4,共 108)。点数 > 0 命中。
- 修正:目标与你之间**每隔一人 −1**(取最短路);扫射 −2;向前翻滚 +1;静滞力场 −1;致命闪光 −999;微型黑洞被射时 −1。
- **爆头**:无视修正直接命中,伤害 +1(技能检定时算 5 点,不可增减)。**哑火**:无视修正必不中(算 0 点)。
- 流程:选目标 → 目标可用【翻滚】(向后翻滚)抵消这 1 发 → 否则判定 → 命中 1 伤。翻滚只抵 1 发,扫射 3 发要 3 张翻滚,逐发结算。
- **自己不能射自己**;可以射别人面前的延时牌(占射击次数,命中后选提前引爆或作废)。

### 2.5 安全协议(节奏控制)
开局正面:每人每回合只能用 1 张【点射】或【扫射】。**第一个角色死亡**时翻面:射击牌无次数限制,且点射/扫射可互转。（1V1 模式里一名角色阵亡也解除。）

### 2.6 死亡
血量 ≤0 濒死,【补丁】回 1(任何人可救);死则亮身份、弃所有牌、结算奖惩。NPC 血到 0 直接死、无濒死。

### 2.7 牌表(基础包,照片所见)
- **基本牌**:点射(1 弹 1 伤)、扫射(清空弹匣连射,判定 −2)、翻滚(向前:下一张射击牌判定 +1,每回合限一次 / 向后:抵消 1 发子弹)、补丁(回 1 / 救濒死)。
- **战术牌**:化血为剑(令一名血 ≥ 你的角色摸 2,其 1 血转为你 1 子弹)、轮盘赌(其一张手牌 + 牌堆顶 5 张混洗轮流翻,翻出射击牌者受 2 伤;FAQ:受伤即止)、静滞力场(别人对你判定亮牌后用,点数 −1 且你摸 1)、**夺取 / 剥离 / 无中生有 / 无懈可击 / 归零斩**(说明书与 FAQ 提到、消耗子弹或技能引用,照片未拍到,文字待补)。
- **延时战术牌**(横版,放目标面前,其回合开始引爆;可被射击/剥离/无懈):微型黑洞(放自己面前,下回合开始时所有其他角色各受 2 伤;提前引爆则失效;对此牌判定 −1)、致命闪光(目标下回合所有人判定 −999)、EMP 清道夫(目标及相邻各 1 伤)。
- **装备牌**(≤3 件):真理之眼(点射未被翻滚则免判定直接命中)、手臂拓展(补给 +1)、彩虹弹匣(子弹上限 +1)、无声的伪装(对你的判定失败时摸 1)、挨打机器人(别人优先拿/弃它,离开装备区摸 2)、偏折头盔(扫射与爆头对你无效)、自我遥控器(补给与子弹上限互换,可对任意人用)、空气压缩炮(点射不耗子弹)。
- **规则牌**:安全协议(双面)、超意识;身份牌 4 种;NPC:占坑机器人(2 血,纯占位)、金币机器人(3 血,杀之摸 3)。

### 2.8 1V1 模式
两侧各放 1 NPC;各发 5 张角色选 2 张、亮出、选 1 出战;先手首回合少摸 1;每回合开始可切换出战角色,两角色血量分开算;一名阵亡 → 弃手牌重摸 4、保留装备、切另一名,安全协议解除;两名全亡即负。

## 4. 与三国杀/风声房间架构的对照 —— 接入评估

共用层(`prototype/common/`:RoomBase 座位/身份/可见性、RoomDOBase、RoomClient 搜索弹层、四位房间码)**原样可用**,和风声一样新建 `prototype/qmxy/`:`shared/qmxy-data.mjs`(24 将 + 牌表)+ `shared/qmxy-logic.mjs`(`QmxyCore extends RoomBase`)+ `worker.mjs`(`QmxyRoomDO extends RoomDOBase`,路由 `/qmxy`、`/api/qmxy/<码>/ws`,wrangler 新 DO 绑定 + 迁移)+ `client/qmxy.html` + `qmxy-sim.mjs`。

**和三国杀房间不同、需要新写的东西**(按"线下辅助"形态,实体牌在桌上):
1. **身份系统换表**:4 身份 + 人数配置表 + NPC 补位(3 人 3 NPC);脑候选 5 张先选先亮;超意识是否生效由配比自动算;异变单挑夺取超意识。三国杀的「主公技/忠内反」概念不复用,但发身份、亮身份、死亡公开的流程同风声。
2. **角色三属性**:血量 / 补给 / 子弹上限,左慈 0/0 为动态。座位卡要显示三个数,而不是三国杀的单体力。
3. **弹匣台账**(新):每人每回合子弹补满、射击/夺取/剥离/无中生有耗弹、化血为剑/止干戈/噬恶之心等改子弹;可做成和血量条并列的计数器。
4. **命中判定辅助**(可选,最有价值的工具):输入"射手、目标",自动算间隔人数修正(座位环最短路)+ 当前修正(翻滚 +1 / 扫射 −2 / 静滞 −1 / 闪光 −999),翻牌点数后给出命中/爆头/哑火结论;带孙鲁班反转、吕布 4 点爆头、小乔流弹方向、甄宓/司马懿"恰好命中"判定。这是三国杀房间完全没有的新模块。
5. **安全协议开关**:全局状态,首个死亡自动翻面并广播。
6. **不需要**三国杀房间里的:距离/马、势力、武将技能工具大部分(24 将技能简单,优先做徐庶窥探灵魂的"看两人手牌"保密工具、霍光"猜命中"、轮盘赌随机器)。

缺口 / 待办:
- 照片未覆盖:说明书第 1~4 页(背景/组件清单/四身份说明)、第 10 页、**夺取 / 剥离 / 无中生有 / 无懈可击 / 归零斩 / 补丁** 的牌面原文与张数;4 人、9 人、10 人身份表;游戏牌 165 张的完整构成(108 张带命中点数的游戏牌 + 24 将 + NPC + 身份/规则牌 + 血量弹夹牌)。贴吧「卡牌展示(15)(18)」两帖没搜到,可能就在那里。
- 扩展《雾区·呓语》10 将技能与"深渊"规则细则(刚上市 3 天,只有视频)。
- 需用户确认形态:线下辅助(同风声)还是数字桌面(要完整牌堆构成)。
