# 无名杀武将技能 vs OL 原文 —— 对齐审计(2026-11-22)

范围:线上将池(军争默认名单 + 素将池 / 顶级阴间两个套组 + 斗地主池)共 290 个武将。以我们武将库(`prototype/sgs/shared/generals.json`)里的 OL 官方原文为准,和无名杀里按名字对上的武将逐技能比对。

方法:浏览器里用扩展同一套匹配规则把每个武将对到无名杀 id,导出技能描述;文字相似度 + 数字比对自动放行 188 条,其余 372 条逐条人工判定(5 个子代理分批读完,主会话复核有争议的)。只比了**描述文字**,描述和代码不一致的在修的时候以代码为准另行核对。

结果:248 个武将对上,42 个无名杀里没有;372 条里 256 条只是措辞不同,75 条有细节出入(见文末),**41 条机制明确不同**。
