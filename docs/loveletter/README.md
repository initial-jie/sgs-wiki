# 《情书》(Love Letter)研究笔记 —— 2026-11-20

> 目的:把情书接到 sgs-wiki 多游戏房间架构(`prototype/common/`)上做**第六个游戏**,形态是**线上牌桌**(系统洗牌发牌、手牌保密、效果即时结算),线上线下通用。
> 本文是规则综述与版本对照;卡面来源在 **`art-sources.md`**。
> 一手来源:Wikipedia「Love Letter (card game)」、UltraBoardGames 规则页与角色页(子代理抓取,2026-11-20)。Z-Man 官方规则书 PDF 抓到了但本机没有 PDF 渲染工具,2019 版的标记表按我记忆填的(见 §4 待核对)。

## 1. 产品事实

| 项 | 内容 |
|---|---|
| 名称 | Love Letter(2012,设计 Seiji Kanai / 金井精二;日版 Kanai Factory「ラブレター」,英文版 AEG 2012~2018,2018 起归 Z-Man Games);中文通称「情书」,繁中版新天鹅堡 |
| 定位 | 2~4 人(新版 2~6)、15~20 分钟的微型推理牌:**16 张牌**,每人手里只有一张 |
| 原版 | 16 张角色卡 + 4 张参考卡 + 爱慕标记(红色木块) |
| 2019 新版(Z-Man) | 21 张:加 间谍×2、大臣×2、侍卫 +1,国王/伯爵夫人/公主 点数各 +1;6 张参考卡;13 枚标记;新美术 Andrew Bosley。去掉新加的 5 张即可按原版玩 |
| 衍生 | Premium(新增 9 角色 + 3 侍卫,至 8 人)、Batman / Adventure Time / Hobbit / L5R / 龙与地下城 / 星战 等主题版;**组队版**见 §5 |

## 2. 规则(原版)

### 2.1 牌表(16 张)

| 点数 | 牌 | 张数 | 效果 |
|---|---|---|---|
| 1 | 侍卫 Guard | 5 | 指定另一名玩家并猜一张牌(**不能猜侍卫**);猜中对方出局 |
| 2 | 神父 Priest | 2 | 偷看另一名玩家的手牌(只有自己看) |
| 3 | 男爵 Baron | 2 | 与另一名玩家秘密比手牌,点数低者出局;相同无事 |
| 4 | 侍女 Handmaid | 2 | 到自己下个回合开始前,不受其他玩家牌效果影响(不能被选为目标) |
| 5 | 王子 Prince | 2 | 指定任一玩家(含自己)弃掉手牌(不结算效果)并补抽一张;牌堆空则抽开局盖掉的那张;弃的是公主则出局 |
| 6 | 国王 King | 1 | 与另一名玩家交换手牌 |
| 7 | 伯爵夫人 Countess | 1 | 打出无效果;手里同时有国王或王子时**必须打出**(不必说明原因) |
| 8 | 公主 Princess | 1 | 无论因何打出/弃掉,立刻出局 |

### 2.2 一轮流程
1. 洗 16 张,**盖掉顶上 1 张**不看(本轮不用)。**2 人局再翻开 3 张**放旁边(公开,不用)。每人发 1 张。
2. 轮到你:**抽 1 张**,从两张里**打出一张**结算效果,另一张留手。顺时针。
3. 出局者手牌翻开进自己弃牌堆(不结算)。
4. **轮末**:只剩一人 → 他赢;或某人回合结束时牌堆已空 → 在局者比手牌点数,最高者赢;同点 → 比各自弃牌堆点数**总和**;再同 → 都赢(都拿标记)。
5. 赢家拿 1 枚爱慕标记,下一轮由他先手。首轮先手官方规则是「最近约过会的人」,房间里随机。
6. **集满标记即胜**:2 人 7 / 3 人 5 / 4 人 4。

### 2.3 边界(实现时都按这些做)
- 受侍女保护的人不能被选为目标。若其他在局者**全部**受保护:侍卫/神父/男爵/国王打出**无效果**(仍要打出);王子**必须选自己**。
- 王子对自己:弃掉剩下那张并补抽;牌堆空则抽开局盖掉的那张。
- 伯爵夫人强制:只在手里**同时**有伯爵夫人 + 国王/王子时;其他组合可自由出。
- 男爵平手无事;比牌结果双方都看到对方的牌(房间里写进私密笔记)。
- 公主被王子逼弃也算出局。

## 3. 2019 新版差异(21 张,2~6 人)

| 点数 | 牌 | 张数 | 效果 |
|---|---|---|---|
| 0 | 间谍 Spy | 2 | 打出/弃掉无效果;**轮末**仍在局且是**唯一**打出/弃过间谍的人额外 +1 标记 |

## 4. 房间实现要点与待核对

- 两个版本做成房内**可切换**(`config.edition`:`classic` 默认 / `v2019`),所需标记可房规覆盖(`config.tokens`)。
- 轮到谁**自动抽牌**(不用点「抽」),出牌面板里选目标 / 侍卫猜牌;大臣是子阶段。
- 保密:手牌只有本人可见;神父/男爵结果只写进本人「私密情报」;弃牌堆、受保护、出局、标记、牌堆张数、2 人局翻开的 3 张公开;轮末全公开手牌。
- **待核对**:2019 版所需标记表(2:6 3:5 4:4 5:3 6:3)我没从官方 PDF 核到,实卡参考卡上有,以实卡为准改 `ll-data.mjs`;UltraBoardGames 说轮末平手比弃牌总和,原版规则书同;大臣「牌堆不足两张」的处理按新版规则书常识做(抽剩下的)。
