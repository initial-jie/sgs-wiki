一键下载(在你自己的终端跑,浏览器 UA 下 CDN 通常放行):

```bash
mkdir -p assets/onuw && cd assets/onuw && grep '^| `' ../../docs/onuw/art-sources.md | while IFS='|' read -r _ fn url _; do fn=$(echo "$fn" | tr -d ' `'); url=$(echo "$url" | tr -d ' '); [ -n "$url" ] && curl -sL -A 'Mozilla/5.0' -o "$fn" "$url"; done; ls | wc -l
```

## 🎵 背景音乐(BGM)

页面顶栏 🎵 开关播的曲子来自 `assets/onuw/bgm.json` 清单(`{"tracks":[{"file","title","credit"}]}`),在 🎚️ 面板里选曲、本机记忆;没有清单就直接找 `assets/onuw/bgm.mp3`;都没有(或选"合成氛围音")就用页面合成的暖色铺底。

推荐曲目都来自 Kevin MacLeod 的 **incompetech.com**,授权 **CC BY 4.0**(免费,可商用,只要求署名;署名文字见每条 `credit`,页面会在 🎚️ 面板和开播时显示)。直链格式 `https://incompetech.com/music/royalty-free/mp3-royaltyfree/<曲名>.mp3`。

| 放到 assets/onuw/ 的文件名 | 曲名 | 时长 / 大小 | 感觉 |
|---|---|---|---|
| `goblin_king.mp3` | The Path of the Goblin King | 3:26 / 7.9MB | 作者自评"Spooky Light":童话式的神秘,带点俏皮,**结尾接回开头可循环**。最贴狼人夜晚主题 |
| `midnight_tale.mp3` | Midnight Tale | 2:42 / 6.2MB | 吉他+鲁特琴,"围着酒馆炉火讲故事",温暖平静 |
| `teller_of_tales.mp3` | Teller of the Tales | 3:32 / 6.5MB | 鲁特+吉他拨弦二重奏,安静、略神秘 |
| `suonatore.mp3` | Suonatore di Liuto | 2:24 / 4.4MB | 极简鲁特琴背景,神秘+放松 |
| `mystery_bazaar.mp3` | Mystery Bazaar | 2:38 / 4.8MB | 桑图尔琴+弦乐,"来我的火盆边取暖",神秘偏暗但不恐怖 |
| `snow_queen.mp3` | The Snow Queen | 3:40 / 8.4MB | 童话式的"有点兴奋有点诡异",比 Goblin King 更有戏 |
| `soaring.mp3` | Soaring | 6:20 / 11.6MB | 合成器铺底,放松里带一点神秘;长局不腻 |
| `ambiment.mp3` | Ambiment | 22:53 / 52MB | 慢速音色+轻钢琴,基本协和;23 分钟一局不用循环 |

一键下载(选你要的几首即可;`bgm.json` 顺序就是面板里的顺序,第一首是默认):

```bash
mkdir -p assets/onuw && cd assets/onuw && B="https://incompetech.com/music/royalty-free/mp3-royaltyfree" && curl -L -o goblin_king.mp3 "$B/The%20Path%20of%20the%20Goblin%20King.mp3" && curl -L -o midnight_tale.mp3 "$B/Midnight%20Tale.mp3" && curl -L -o teller_of_tales.mp3 "$B/Teller%20of%20the%20Tales.mp3" && curl -L -o suonatore.mp3 "$B/Suonatore%20di%20Liuto.mp3" && curl -L -o mystery_bazaar.mp3 "$B/Mystery%20Bazaar.mp3" && ls -la
```

{"tracks":[
