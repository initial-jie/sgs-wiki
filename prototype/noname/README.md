# 无名杀(noname)私用部署资料

- `hall-do.mjs` —— 联机大厅中转的 Durable Object 移植(worker 路由 `/noname/`,协议同官方 `packages/server`)。
- `patches/static-hosting.patch` —— 对 noname 仓库(基于 `4175c09`,2026-11-21;更老的基线不保证能套,武将技能文件上下文会变)的改动:`init/browser.js` 无文件后端时退化为只读静态适配器;`library/index.js` 默认 hallURL 指向我们的 DO + 菜单默认值;`mode/connect.js` 首次取昵称并直连大厅;`game/config.json` 默认值(关自动确认/问无懈自己/显示不无懈按钮/跳过新手向导);`init/index.ts` 手机免触屏确认;`mode/identity.js` + `layout.css` 身份局变体「暴虐无道」「大忠似奸(含昏君二线变种)」「失心疯」「无间道」。联机换将卡(`lib.sgsSwap`,房间设置「启用换将卡」默认开:起手候选每张各可换一次,换上来的不能再换,主公技候选不能换)。联机「选将时限」(房间设置,默认 5 分钟,`game.randomMapOL` 里选将期间临时替换 choose_timeout);文字提示(技能名等)停留 ~3 秒;历史记录栏居中时的位置微调(默认打开由扩展迁移 v3 做)。联机「同时选将」(`sgsChooseTogether`,房间设置默认开);2026-11-22 按 OL 原文对齐的一批武将技能(清单见 `docs/noname-ol-audit.md`,改动散在 `character/{sp,clan,onlyOL,xianding,diy,yijiang,refresh}/`,都带「【私用补丁】」注释)。联机倒计时到点只代选一次、不持续托管(`game/index.js countChoose`,2026-11-23)。另有两处对上游武将 / 核心的修正(2026-11-21):`character/sp/skill.js` 徐荣〖凶镬〗第三项按 OL 原文改成「一张手牌 + 一张装备区的牌」;`library/element/player.js` `sortHandcard` 修「把手牌完全倒过来不生效」(蒋琬〖自若〗两张牌互换)。
- `patches/jit-service-worker.patch` —— jit service worker 同源也拦截(线上 .ts 扩展即时编译)。
- `extension/sgs-friends/` —— 我们的无名杀扩展(内置 play 包):① 将池——开局从 worker `/api/noname-pool` 读白/黑名单(按武将名+势力),对到无名杀 id,池外武将全部禁用(本地+联机建房);同名武将并成一个坑(一张候选 + 「切换」,规则同房间发将);建房 / 房间设置里可选「将池套组」(`connect_pool_set`,选项 = `/pool` 页维护的套组,选了就整份换用那套黑白名单;套组只在 `/pool` 维护);线下将里上游已有的按 `DIRECT` 直连;② 名字即账号:昵称哈希成联机 key,头像等资料存 worker `/api/noname-profile`,同名跨设备同一人,大厅点自己名字 / 扩展页可改名换头像,`/players` 名册;③ 身份局变体入口在 identity.js 补丁里。**装法**:`cp -R prototype/noname/extension/sgs-friends <noname>/apps/core/extension/`,补丁里已把它登记进 `game/package.js` 的 play 表、`config.json` 的 `stockextension`,并在 `init/index.ts` 强制加载。
- `check-upstream.sh [武将名…]` —— 看无名杀上游最近提交、我们补丁基线之后的新增提交数,以及某些武将上游是否已实现(GitHub 代码搜索 + 取 translate 行,需 `gh` 已登录)。上游有了新将 → 重 clone + 打补丁 + 复制扩展 + build + postbuild + deploy,将池按名字自动对上。
- `postbuild.sh` —— `pnpm build` 之后、`wrangler pages deploy` 之前跑:`node_modules`→`nm` 改名+改写引用、加 `404.html`、加 `_headers`。

完整流程与验证法见 `docs/HANDOFF.md`「🧪 线上牌桌方向」。
